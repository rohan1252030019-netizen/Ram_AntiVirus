# Security Policy

Report vulnerabilities privately via email, NOT public issues.

**Email:** security@<domain> (contact repository maintainer)

We acknowledge within 48h and fix within 7 days.

## Notice Regarding Historical Secrets & Credentials

> [!WARNING]
> Any API key, token, master key, or password found in git commit history prior to this hardening release must be considered **compromised**.
> Never reuse keys or passwords that were previously checked into the repository or published in demo files. All production environments must generate fresh, high-entropy secrets and rotate any legacy credentials immediately.
